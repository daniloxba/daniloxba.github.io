Política de privacidade do Continuum

Vigente desde 23/09/2026.

Quem usa

O Continuum é um aplicativo pessoal. O único usuário é o próprio dono, que também é quem o desenvolveu e o executa no seu computador.

Que dados do Google o aplicativo acessa

  • Google Agenda — somente leitura: para ler as datas de aniversário que o dono registrou na própria agenda.
  • Google Contatos — somente leitura: para ler nome, telefone e data de aniversário dos contatos do próprio dono.

O aplicativo não altera, não apaga e não cria nada na conta Google.

Onde os dados ficam

Somente no computador do dono, num banco de dados cifrado. Nada é enviado a servidores do desenvolvedor (não existe nenhum), nem vendido, compartilhado ou usado para publicidade. As cópias de segurança também são cifradas.

Uso dos dados do Google

O uso das informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Como revogar

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.
